TÂCHE 2 — Extraction des screens Figma
--------------------------------------------------------------------------------

COMMANDE UTILISÉE :
  /extract-figma-screen --url https://www.figma.com/design/xctSRqtM653zRS7QY3KMm0/Measure---GEO-Module?node-id=4448-11715&m=dev

PRÉREQUIS :
  - FIGMA_TOKEN : Personal Access Token Figma (format : figd_xxxxxxxxxxxxxxxxxxxx)
    → Fourni manuellement dans le chat au moment du déclenchement
  - URL Figma avec le node-id pointant sur la section à extraire

MÉTHODOLOGIE :
  1. Appel API Figma : GET /v1/files/{file_id}?depth=5
     → Récupération de la structure complète du fichier
     → file_id extrait de l'URL : xctSRqtM653zRS7QY3KMm0
     → node ciblé : 4448:11715 (section "GEO - Onboarding", page "Onboarding V.2")

  2. Filtrage des frames :
     → Exclusion des frames de type N0TE (annotations design)
     → Conservation uniquement des frames type FRAME (screens UI réels)
     → 55 frames détectés → 40 screens retenus

  3. Export via API Figma : GET /v1/images/{file_id}?ids={id1},{id2},{id3}&scale=2&format=png
     → Batches de 3 frames maximum pour éviter les timeouts
     → 14 batches effectués, 0 erreur

  4. Téléchargement des PNGs :
     → Chaque URL retournée par l'API est temporaire (~10 min)
     → Téléchargement immédiat après chaque batch

STRUCTURE DE SORTIE :
  figmaScreens/
