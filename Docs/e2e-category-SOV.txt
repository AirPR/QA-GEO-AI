Scenario: TC-GEO-663-002 — Category: KPI row shows exactly 4 cards without SOV
          and layout reflows cleanly
================================================================================

  When the Performance KPI row renders

  Then exactly 4 KPI cards are displayed:
       Visibility | Avg Position | AI Choice | Sentiment
    And no "Share of Voice" KPI card is rendered
    And the KPI row layout reflows cleanly for 4 cards
        (no broken grid, no empty cell where the SOV card used to be)


================================================================================
Scenario: TC-GEO-663-004 — Category: Brand Rankings table has no SoV% column
================================================================================

  Given the user is on a Category view

  When the Brand Rankings table renders

  Then the table columns are exactly: Rank | Brand | Visibility% | Avg Position | LLM Choice%
    And no "SoV%" column header is present
    And no "SoV%" cell exists anywhere in the table (headers or data cells)

Scenario: TC-GEO-664-002 — SOV dedicated card renders below KPI row on Category view
================================================================================

  Given the user is on a Category view with data available

  When the page finishes loading (skeleton gone)

  Then a full-width "Share of Voice" card is visible directly below the KPI row
    And the card heading "Share of Voice" is visible
    And the subtitle "By brand, your brand is highlighted" is visible
    And the card displays one of:
        - a doughnut SVG chart (when data is available)
        - an empty state ("No data to show")
        - an error state ("Couldn't load this chart")
