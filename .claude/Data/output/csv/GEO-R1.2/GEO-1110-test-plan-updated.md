### QA Test Plan for GEO-152 — Actions Center — Target Sources

**Updated:** 2026-09-16 | **Previous version:** GEO-1110 (2026-09-08) | **Source CSV:** testcases-coverage-epicGEO-152.csv (98 TCs)

**Objective:** Verify the end-to-end verification funnel, the Target Sources ranked list, the verdict tabs and filters, the evidence explanation panel, the analysis export, and the two AI Citation Sources changes (Favorability removal + Related Prompts) within the Actions Center.

#### Test Scenarios & Detailed Test Cases

**Suspect Source Qualification (stories: GEO-1116)**

- Scenario 1: Qualification Logic - A source qualifies only if cited where the brand is entirely absent (visibility), not the winner (competitive), or in a negative concept answer. Brand present but not ranked 1st does NOT qualify.
- Scenario 2: Domain Exclusion - Brand-owned and competitor domains are excluded from the suspect set. No upper cap on the qualifying set.
- Scenario 3: MODEL_DECLARED Exclusion - URLs written from model memory (not fetched via web search) never qualify any source, even when cited in a qualifying answer.

**Article Verification Funnel (stories: GEO-1117 & GEO-1119)**

- Scenario 4: Depiction Check - Brand absent → failing article, no passage. Brand named negatively → failing article, verbatim passage capped at 140 chars. Brand named neutrally or positively → positive article kept in a dedicated panel tab, no effect on rank or failing counts.
- Scenario 5: Unfetchable & Incomplete Articles - Both contribute 0 to failing counts and rank (service unavailable, unsupported language, or unusable content treated the same as unfetchable).
- Scenario 6: Source Elimination - A source whose failing article count reaches zero after full verification does not appear in the Target Sources list.
- Scenario 7: Progress State - "Verifying sources" state shown while running; no partial list ever displayed. List appears automatically on completion without a full page reload.

**Ranked Target Sources List (stories: GEO-1118)**

- Scenario 8: Ranking & Views - Order by descending failing article count; ties broken by reason badges then citation count. Card and table views available via toggle with identical fixed order (no user-triggered sort).
- Scenario 9: Source Type Filter - Lists only types present in the current scope, each with its count. Default entry: "All source types."
- Scenario 10: Verdict Tabs - Three tabs: All (default), Improve visibility, Improve perception. Each tab ranks independently; sources absent if they have no failing articles in that verdict scope. Both badges shown simultaneously on a card. Empty tab shows a message. Pagination: top 10 shown first with explicit control to reveal the rest.

**Explanation Panel (stories: GEO-1123)**

- Scenario 11: Open/Close - Panel opens on card selection; closes on re-selection of the same card.
- Scenario 12: Panel Tab Isolation - Panel always shows all failing articles across both verdicts regardless of the active verdict tab. Card count (verdict-scoped) and brief count (full) deliberately differ — expected behavior, not a defect.
- Scenario 13: Deterministic Brief - Four fixed templates based on article composition (all-absent / all-negative / both / with positive articles appended). The brief text is deterministic (no AI generation). A "generated by AI" disclaimer is present on the brief block — it refers to the AI article qualification, not to the brief text. Singular form enforced (n=1 → "1 unfavorable article"). No recommendation sentence.
- Scenario 14: Article Evidence - Brand-absent articles show a no-mention indication with no passage. Negatively-named articles show a verbatim passage with brand highlighted, capped at 140 chars. Citing engine icons shown alongside each failing article.
- Scenario 15: Positive Articles Tab - Shown when the source has positive articles (title, address, verdict, passage, citing engines). Absent when source has none. No effect on rank, badges, or counts.

**Filters & Scoping (stories: GEO-1120 & GEO-1122)**

- Scenario 16: Filter Recompute - Applying Country, Category, AI engine, date range, or source type filters recomputes failing counts, citation counts, badges, and order within the selected scope. Source with zero failing articles after recompute is absent from the list.
- Scenario 17: Filter + Verdict Tab - When both a scope filter and a verdict tab are active, the filter scopes first; the tab applies within the filtered results.
- Scenario 18: 7-day Minimum Window - Actions Center pools at least 7 days regardless of selected range. AI Citation Sources uses the exact selected range — different periods on short ranges are expected behavior.
- Scenario 19: Source Type Filter Independence - Source type filter active on screen has no effect on the exported Target Sources section.
- Scenario 20: Scope Additions & Verdict Lifecycle - Any Manage Scope change (Country, Topic, AI Engine, or Question) takes effect on the next scheduled execution, which produces a new snapshot with a complete re-analysis. New articles are verified under the same rules. On every run, each article is re-checked via a conditional request: an unchanged page reuses the stored verdict (no full re-fetch, no re-judgement); a changed page is re-fetched and re-judged. The staleness window overrides the conditional response and forces a full re-fetch and re-judgement regardless. The target list after completion covers the full scope of that run.

**Empty State (stories: GEO-1121)**

- Scenario 21: All-clear - When no source survives the verification funnel, the all-clear message is shown alone. No source list is rendered beneath it. (Healthy Source Row component removed from scope 2026-09-14.)

**Analysis Export (stories: GEO-1124)**

- Scenario 22: Scope Independence - Export always uses All tab data with total failing counts regardless of the active on-screen tab or source type filter.
- Scenario 23: Excel - Target Sources tab: ranked list, brief, failing articles with verdicts and citing engines, failing prompts.
- Scenario 24: PowerPoint - Brief + failing article count split per source. Overflow sources represented by totals.
- Scenario 25: Export State Handling - Verification still running → verifying state. No source survives → all-clear message shown alone.
- Scenario 26: 7-day Window in Export - Export applies the same 7-day minimum window rule as the in-product Actions Center view.

**Favorability Removal from AI Citation Sources (stories: GEO-1125)**

- Scenario 27: Removal - Favorability column, sort key, and badge removed from the card table, All Domains modal, XLSX/PPTX exports, and the Lite/PQL result table. This is a full removal, not a hide. Remaining columns: Domain, Type, Frequency only.
- Scenario 28: Regression Guard - Questions Analysis filter, question detail panel, Corporate Reputation sheet, Raw Data sheet, stacked bar, legend, source type filter, logos, and source details panel must be unchanged by the removal.

**Related Prompts in AI Citation Sources (stories: GEO-1126)**

- Scenario 29: Related Prompts Section - Per-source domain panel shows prompt previews with engine icons and an "All related Prompts (N)" control; modal headed with domain name + count and a search field.
- Scenario 30: Prompts Modal Tabs - Four tabs: All (default), Visibility, Competitive, Perception. Prompt cited by multiple engines = one row with all engine icons. Search is additive to the active tab. Perception tab counts questions, not individual concepts.
- Scenario 31: Cited URLs Section - Shows count heading, URL previews, and "All Cited URLs (N)" control with a search field.
- Scenario 32: Consistency - Total prompt count must be identical in the panel control, modal header, and sum of tab counts.
- Scenario 33: Scope - Panel reflects active market, engine, and date filters of the dashboard. 7-day minimum window of the Actions Center does NOT apply to this panel.

#### Edge Cases & Boundary Conditions

* Brand present but not ranked 1st (visibility leg): Source does NOT qualify on that leg.
* MODEL_DECLARED URL cited in a qualifying answer: URL excluded; source not added to suspect set.
* Article check could not be completed (service down, unsupported language): 0 contribution — treated the same as unfetchable (distinct edge case).
* Source with both Improve Visibility and Improve Perception badges: Both badges shown simultaneously on the card across all tabs.
* Card count ≠ brief count when a verdict tab is active: Expected behavior, not a defect.
* Brief singular form (n=1): "1 unfavorable article" (no plural).
* Passage exactly 140 characters: Displayed in full, not truncated.
* Passage exceeds 140 characters: Capped at 140 chars.
* Domain logo missing: Neutral placeholder shown.
* Report younger than 7 days: Every available day used (no extension beyond available data).
* Actions Center vs AI Citation Sources on range < 7 days: Different periods shown — expected behavior.
* Source whose failing count reaches zero after verification: Absent from Target Sources list.
* Empty verdict tab in prompts modal: Message shown; other tabs reachable.
* Prompt cited by multiple LLMs: Single row with all engine icons.
