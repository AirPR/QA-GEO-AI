# Règles de sélection Playwright — cas spécifiques

## Plusieurs lignes identiques dans un tableau
- **Interdit** : `.locator('tr').filter({ hasText: BRAND }).first()` si plusieurs lignes peuvent correspondre
- **Obligatoire** : chaîner un second `.filter()` :
  ```js
  page.locator('tr').filter({ hasText: BRAND }).filter({ hasText: 'In progress' }).first()
  ```

## Toggles React (re-query pattern)
- **Interdit** : `.all()` ou snapshots de handles — stale après re-render React
- **Obligatoire** : re-requêter `[aria-checked="true"]` à chaque itération :
  ```js
  for (let guard = 0; guard < 10; guard++) {
    const checked = page.locator('[aria-checked="true"]');
    const cnt = await checked.count();
    if (cnt === 0) break;
  }
  ```
- Toujours `.nth(i)` sur la requête fraîche — jamais sur un index drifté

## Dropdowns "valeur active seulement"
- Ouvrir le dropdown avant d'asserter les autres valeurs
- Sélecteur options : `page.locator('[role="option"]:has-text("...")')`
- Fermer avec `page.keyboard.press('Escape')` après l'assertion

## Pages category — onglet Performance (KPI cards)
- Cliquer l'onglet Performance après navigation, avant toute assertion KPI
- Sélecteur : `[role="tab"]:has-text("Performance")`

## Snapshot navigator — deux patterns distincts
- **Pages category** : bouton dropdown `button:has-text("Analysis —")` → option `[role="option"]`
- **Pages overview/epic** : liste déroulante → cliquer directement sur le texte cible
- **`H.ensureSnapshot()` — OBLIGATOIRE** : toujours utiliser le helper depuis e2e-helpers.js

## Recharts ScatterChart — Brand Prioritization Matrix
- `circle[r]` avec `title="N items at this location"` → cluster de N brands
- `foreignObject` ou `g[aria-label]` → 1 brand individuel
- Ne jamais comparer `circle.count()` aux valeurs de légende (sous-compte garanti)
- Vérifier les deux patterns (`foreignObject` direct ET `g[aria-label] > foreignObject`) pour staging + prod
- Pattern prod :
  ```js
  const brandGs = Array.from(scatter.querySelectorAll('g[aria-label]')).filter(g =>
    (g.getAttribute('aria-label') || '').toLowerCase().includes(targetBrand.toLowerCase())
  );
  for (const g of brandGs) {
    const fo = g.querySelector('foreignObject');
    if (!fo) continue;
    const x = parseFloat(fo.getAttribute('x') || '0');
    const y = parseFloat(fo.getAttribute('y') || '0');
    const w = parseFloat(fo.getAttribute('width') || '0');
    const h = parseFloat(fo.getAttribute('height') || '0');
    quadrantCounts[classify(x + w/2, y + h/2)] += 1;
  }
  ```

## Tooltips Radix UI
- Boutons (i) : hover (pas clic) → `locator.hover()`
- Sélecteur : `[role="tooltip"]` — vérifier avec `.toBe()` (exact)

## dismissCookieBanner — limitation
- Cible `[data-testid="cookie-banner"]` — ne fonctionne pas si ce testid est absent
- La bannière non fermée peut bloquer des clics en bas de page

## Compatibilité staging / prod — Labels UI renommés
| Staging | Prod | Pattern robuste |
|---------|------|-----------------|
| `Market` | `Country` | `/Country|Market/i` |
| `All Markets` | `All Countries` | `/all (markets?|countries)/i` |
| `AI Citation Sources` | `LLM Engines Citation Sources` | sélecteur multi-valeur |

## Boutons LLM — sélecteur universel
- **Correct** : `button[aria-label="Claude"]` — fonctionne staging + prod
- **Interdit** : `button:has(img[alt="claude"])` — les alt peuvent être vides
```js
const LLM_ARIA_LABELS = ['Claude', 'Gemini', 'Grok', 'ChatGPT', 'Perplexity'];
for (const label of LLM_ARIA_LABELS) {
  const btn = page.locator(`button[aria-label="${label}"]`);
  if (await btn.isVisible({ timeout: 1000 }).catch(() => false)) { /* ... */ }
}
```
