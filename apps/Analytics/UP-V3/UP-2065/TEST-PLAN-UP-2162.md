### QA Test Plan for UP-2162 — AI disclosure for Analytics (epic UP-2065: UP Analytics: Global Analytics Core v3)

**Updated:** 2026-11-03 | **Source CSV:** none (no TC CSV found for UP-2162 / UP-2065) | **Status:** Approved 2026-11-04

**Objective:** Under the EU AI Act (Article 50), AI-generated text in Analytics must say so where the user reads it. This plan checks that every AI text block (AI Chart Insights panel and the Analytics Report AI Insight block) shows the AI Summary disclaimer ("✦ Summary generated by artificial intelligence"), that the panel attribution (Powered By header / AI Sense footer) is kept, that loading, empty and error states keep the attribution, that the AI header/statement survives every report export path (PDF, PPT, shared report), and that the strings match the Approved Copy (guidelines section 04), including translations.

#### Test Scenarios & Detailed Test Cases

**AI Disclosure Statement on AI Text Blocks (stories: UP-2162)**

- Scenario 1: Chart Insights Disclaimer - The AI Chart Insights panel shows the visible statement "✦ Summary generated by artificial intelligence" next to the AI-generated text on a dashboard.
- Scenario 2: Report Builder Disclaimer - Each AI Insight block in the Report builder shows the visible AI Summary disclaimer next to the generated text, not only the section title.
- Scenario 3: Disclosure Beyond Attribution - The AI-generated statement is present where the text is read, in addition to (not replaced by) the "Powered by AI Sense" attribution.

**Panel Attribution (stories: UP-2162)**

- Scenario 4: Powered By Header - The AI panel shows the "Powered By" attribution in its header.
- Scenario 5: AI Sense Footer - The AI panel shows the "AI Sense" attribution in its footer.

**Loading, Empty and Error States (stories: UP-2162)**

- Scenario 6: Loading State Attribution - While the AI insight is loading, the panel still shows its attribution.
- Scenario 7: Empty State Attribution - When the AI panel has no insight to display, the attribution is still shown.
- Scenario 8: Error State Attribution - When the AI insight fails to load, the error state still shows the attribution.

**Report Builder and Export Paths (stories: UP-2162)**

- Scenario 9: PDF Export Label - The exported PDF shows the AI header/statement on every AI Insight block.
- Scenario 10: PPT Export Label - The exported PPT shows the AI header/statement on every AI Insight block.
- Scenario 11: Shared Report Label - A shared report shows the AI header/statement on every AI Insight block.

**Approved Copy and Translations (stories: UP-2162)**

- Scenario 12: Approved Copy Strings - The disclaimer, attribution and other AI strings match the Approved Copy (guidelines section 04) in the default language.
- Scenario 13: Translated Strings - The same strings match the Approved Copy translations in each supported language.

**Design Review Evidence (stories: UP-2162)**

- Scenario 14: State Screenshots Review - Screenshots of every state (nominal, loading, empty, error, each export) are captured and checked against the design review checklist (guidelines section 09).

#### Edge Cases & Boundary Conditions

* AI attribution shown alone ("Powered by AI Sense" without the AI-generated statement): not accepted as disclosure; the statement must be present where the user reads the text.
* Loading, empty and error states of the AI panel: the attribution is kept in each state.
* Export of a report containing AI Insight blocks (PDF, PPT, shared report): the AI label is not lost on any path.
* Wording update after copy validation with Product Marketing: handled as a copy swap, current guideline strings apply until then.

#### Open Points (not blocking)

* UP-2162: AC3 (feedback control "Did you like this summary?") is marked "on product surfaces (tbd later)"; the surfaces and the expected behaviour are undefined, so no scenario is written until the PO confirms scope (untestable for now).
* UP-2162: Copy validation with Product Marketing is pending; the expected strings are the current guideline strings and may change (copy swap).
* UP-2162: The list of supported languages for "incl. translations" and the source of the Approved Copy translations (guidelines section 04) are not stated; needed to run Scenario 13.
* UP-2162: "Every AI text block" is not listed; the plan covers the AI Chart Insights panel and the Report builder AI Insight block named in the Context. Any other AI text surface of Analytics is to be confirmed.
* UP-2162: "Powered By header / AI Sense footer" is not specified per surface (panel vs report, on-screen vs export); the exact placement is taken from the Figma design (AI Design Guidelines, Analytics guidance node 14876-1486 from the design task, PO/design comment 868733).
* UP-2162: AC7 is a deliverable (screenshots attached and design-reviewed), not a UI behaviour; Scenario 14 covers the capture and review only (Partial).
* UP-2162: "Shared report" is not defined (link, email, scheduled); the sharing mode to test is to be confirmed.
* UP-2162: Priority comment 869260 asks for a fast go-live; it defines no behaviour and changes no scenario.
* UP-2162: The story has no "As a ... I want ... so that" block; the persona for the preconditions (any Analytics user with access to AI insights and reports) is assumed from the Context.
* UP-2162: Prerequisites to run the tests: Analytics environment with AI Chart Insights enabled and a report containing AI Insight blocks, a way to force the loading, empty and error states, and access to the supported UI languages.
