## Context

The EU AI Act (Article 50) applies since 2 Aug 2026. AI-generated text must say so where the user reads it.
Standard: AI Design Guidelines (Figma) >
https://www.figma.com/design/H9l8o3SVupUgyW6WV4PliW/AI-Design-Guidelines---Proposal?node-id=4001-11 
Reference: AI Disclosure Initiative · Phase 1: AI Summaries (guidelines + Jira template)
https://onclusive.atlassian.net/wiki/spaces/Product/pages/5578358788/AI+Disclosure+Initiative+Phase+1+AI+Summaries 
Context for Analytics:
- Analytics AI Chart Insights panel: Currently shows AI insights with no "generated by AI" statement anywhere on dashboards/reports. Header and footer branding only. Missing feedback control.
- Analytics Report (Report builder + PPT/PDF export): AI Insight block shows generated text with only section title, no statement, no spark, no feedback. Export loses AI label.

## User Story

_No "As a ... I want ... so that" block in the Jira description (technical story). See Context / Acceptance Criteria._

## Acceptance Criteria

Acceptance criteria:
- [ ] Every AI text block shows the AI Summary disclaimer ("✦ Summary generated by artificial intelligence"), visible
- [ ] Panel attribution present (Powered By header / AI Sense footer)
- [ ] Feedback control present ("Did you like this summary?") on product surfaces (tbd later)
- [ ] Loading, empty, and error states keep the attribution
- [ ] Report builder & export: AI header/statement present on every export path (PDF, PPT, shared report)
- [ ] Strings match Approved Copy (guidelines section 04), incl. translations
- [ ] Screenshots of every state attached and design-reviewed (checklist, guidelines section 09)

## Technical Details

Notes:
- The Confluence guidance states attribution alone (e.g. "Powered by AI Sense") is not disclosure; the AI-generated statement must be present where the user reads the text.
- Copy validation is pending with Product Marketing; build with current guideline strings and treat wording updates as a copy swap.
