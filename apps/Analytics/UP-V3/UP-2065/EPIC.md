## Description / Functional Need

**Global Analytics Core v3** continues the evolution of the Onclusive Analytics module started in [UP-1739] (Global Analytics Core v2), focused this round on information-architecture cleanup and consistency work across Core and Premium tiers.

Tighten up the Analytics experience so navigation, entry points, and functionality behave consistently regardless of tier - removing duplicate or diverging paths that accumulated as Premium and Core features evolved separately.

## Scope

Stories under this epic will be scoped and added incrementally as this work is planned. First up: consolidating the Analytics entry point for Core users under Measure (removing the duplicate "Chart Analytics" tab under Mention).
