## Description

Top Concepts Associated with Your Brand — context details panel: source items should be fully clickable.

## Proposed Solution

- Each source list item should be clickable as an entire row, not only via the external link icon. On hover, the external link icon appears to indicate that clicking the row will open the source in a new tab. The click target spans the whole row, not just the icon.
- LLMs are currently shown as plain text. They should be displayed as the corresponding LLM logos instead of their names.
- Same must be applied for the Sources - Topic modal triggered when user clicks on All sources.

## Acceptance Criteria

No structured AC available — see description and Figma reference for expected behavior.

## Technical Details

- Click target: full row (not icon only)
- Link: opens source in new tab on click
- LLM display: logos instead of plain text names
- Applies also to: Sources - Topic modal ("All sources" click)
