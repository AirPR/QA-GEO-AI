## Epic Overview

GEO-440 est un epic de consolidation regroupant tous les ajustements design, corrections de bugs visuels, et améliorations UX ciblées pour la version 0.4. Il couvre 25 éléments : 10 stories, 11 bugs, 3 design tasks et 1 task technique. Les thèmes principaux sont l'harmonisation de l'ordre des LLMs, l'amélioration du wizard d'onboarding, des corrections de logos et de tooltips, un refactoring du layout du rapport, et la cohérence terminologique Reports → Analysis.

## Points Clés

- Canonical LLM order is set in a single constant `LLM_PROVIDER_ORDER` in `/frontend/src/config/llmConfig.js` — changing it propagates everywhere
- Corporate Reputation expand (GEO-395) and Category LLM buttons (GEO-367) are currently Abandoned — retesting recommended on stable environment
- GEO-445 (structural refactor) must not touch data fetching or component contracts
- GEO-449 (design) blocks GEO-446 (implementation) for the last analysis screen
- GEO-451 (design) blocks GEO-447 (implementation) for category suggestion delete UX
- Terminology unification: "Reports" → "Analysis" impacts at least GEO-460 (header) and GEO-482 (empty state); fix for GEO-482 may live in the platform integration layer

## Out of Scope

- Data fetching or component contract modifications
- Rewriting non-applicable body copy in empty state beyond the Reports → Analysis rename
