## Description
Manage Scope currently lets users view the questions. This story adds full management of those prompts in place: add, edit, and delete. Per-category prompts cover visibility, competitive, and perception. Brand image prompts are managed at the scope level (not nested inside categories). Prompts are managed per country, so each market can have its own prompts. Changes are saved against the scope and applied on the next analysis run (they do not retroactively change already-completed results). A version history (Google Docs style) lets users see what was changed over time, and a message informs them that changes take effect on the next run.
