## User Story

> As a user of an unbranded analysis, I want an Overview that shows who leads the topic and what the answers say about it, so that I read the landscape without a brand scorecard.

## Acceptance Criteria

**AC1 — Sidebar block** (Updated 2026-10-09)

- Given: the analysis loads
- When: the sidebar renders
- Then: its block shows the topic's first letter in the logo slot and the topic, as the brand block does today, with no extra header, mode label or date

**AC2 — Hidden widgets**

- Given: the Overview loads
- When: it renders
- Then: the scope bar, the KPI cards and deltas, Time Evolution, Category Prioritization, Corporate Reputation, Brand Territory and the Brand Image hint are not shown

**AC3 — InBrief about the topic** (Updated 2026-10-09)

- Given: InBrief
- When: it is generated
- Then: 3 bullets built from the Category Topics answers and the answers of prompts with the Other type say what the answers say about the topic, may name the brands the answers attach to a topic, and carry "Category summary generated by artificial intelligence"

**AC4 — Dedicated topic prompt** (Updated 2026-10-19)

- Given: an unbranded analysis
- When: InBrief is generated
- Then: it uses a dedicated topic prompt, not the brand Perception summary, with the Category Topics concepts and the concepts of prompts with the Other type (label, sentiment, frequency, attached brands, one quote per topic) of the Overview or the category as input, through the InBrief topic prompt attached to GEO-1209

**AC5 — Format check** (Updated 2026-10-09)

- Given: the generated bullets
- When: they are checked
- Then: only the format is checked (3 bullets of 150 characters max), with no brand-name check, and after the last failed attempt the widget shows its error state

**AC6 — Hidden or empty** (Updated 2026-10-09)

- Given: an analysis or a category with no Category Topics prompts and no prompts in Other
- When: the Overview or the category loads
- Then: InBrief and Top Topics are hidden, since no prompt feeds them; when such prompts exist but returned no topic, both show an empty state

**AC7 — Top Topics** (Updated 2026-10-07)

- Given: Top Concepts
- When: it loads
- Then: it is titled "Top Topics in the Category", and each topic describes the category, never names a brand, has its sentiment towards the category and its frequency, as in Top Concepts today, with no brand tags

**AC8 — Neutral SOV ring**

- Given: the Share of Voice ring
- When: it loads
- Then: it keeps the brand analysis calculation, with no enlarged slice, no centre value and the subtitle "How the answers split across entities"

**AC9 — Landscape table**

- Given: the rankings table
- When: it loads
- Then: it is titled "{topic} landscape", with no highlighted row and tooltips without "your brand"

**AC10 — Citation sources** (Updated 2026-10-09)

- Given: AI Citation Sources
- When: it loads
- Then: its subtitle refers to the topic, its legend has no Owned Media or Competitor Media, there is no Favorability column, and the related prompts modal lists the Category Topics prompts under a "Category Topics" tab

**AC11 — Captions**

- Given: any widget caption
- When: it renders
- Then: it describes the widget and never reminds the user that no brand is set

**AC12 — Analyses list** (new, 2026-10-09)

- Given: the GEO dashboard analyses list
- When: it shows an unbranded analysis
- Then: the column is titled "Brand / Topic" and shows the topic with its first letter, no domain, and the Competitors card also counts the brands detected in unbranded analyses

## Technical Details

### Rules (OS-Team, updated 2026-10-19)

- A brand analysis Overview is unchanged.
- No header, mode label or generation date is added anywhere: the sidebar block is the only « header », as in a brand analysis.
- InBrief may name a brand, but only one the answers attach to a topic (input limited to up to 3 brands per topic); it never ranks brands.
- InBrief receives one quote per topic (the first one met), so its bullets can say why a topic comes up, not only list it.
- InBrief and Top Topics are **hidden** only when no Category Topics or Other prompt exists in the scope; prompts that returned no topic give an **empty state**.
- Top Topics never names a brand (instruction in the analysis prompt, no extra filter) and shows no brand tags.
- The rankings and the SOV ring list the same brands as in a brand analysis (top 10 by SOV, « Others » for the rest), with no brand highlighted.
- New texts are added to the strings sheet in the 4 locales with status « Proposed » and shipped on staging; the PM reviews the wording afterwards.
