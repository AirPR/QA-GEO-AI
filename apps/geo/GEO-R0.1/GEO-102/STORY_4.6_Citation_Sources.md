## User Story

**As** an Editor  
**I want** to see which sources AI engines cite in my category  
**So that** I can identify key publications for PR outreach

## Acceptance Criteria

1. **Given** an Editor on the Overview page, **When** AI Citation Sources loads, **Then** it shows:
   - A stacked bar chart of source types (11 categories)
   - A domain table with:
     - Domain name
     - Source type
     - Favorability (Favorable/Neutral/Unfavorable)
     - Citation count
   - Favorability based on brand's performance in responses citing that domain
